# E2b RF+DF+AWF Surrogate Oracle

> Date: 2026-08-04 | Dataset: CW 512 subset | Experiment: Stage B Teacher Oracle

## Summary

E2b keeps the RF keypoint candidate space and replaces the original Var-CNN surrogate slot with AWF:

```text
rf slot     -> RF
df slot     -> DF
varcnn slot -> AWF checkpoint
```

The CSV field name `varcnn_accuracy` is therefore an implementation slot name in this experiment, not the actual model identity.

## Reproduction Notes

Script:

```text
scripts/stage_b_run_ensemble_oracle_e2b_rf_df_awf.py
```

Use the AWF checkpoint in the third surrogate slot:

```bash
python -u scripts/stage_b_run_ensemble_oracle_e2b_rf_df_awf.py \
  --output_dir results \
  --run_name stage_b_e2b_rf_df_awf_512 \
  --archive results/stage_b_fast_keypoint_full_cw_all_seed0/fast_keypoint_archive.npz \
  --data_root datasets/CW.npz \
  --rf_checkpoint models/attacks/fixed_rf_checkpoint.pt \
  --df_checkpoint wflib_copy/checkpoints/CW/DF/dynapd_clean_seed0.pth \
  --varcnn_checkpoint wflib_copy/checkpoints/CW/AWF/dynapd_clean_seed0.pth \
  --methods norm_weighted_r80_d10_v10 \
  --dummy_budgets 0.15 \
  --max_samples 512 \
  --sample_end 512 \
  --compact_candidate_generation \
  --candidate_batch_size 4096 \
  --candidate_device cuda \
  --candidate_score_device cpu \
  --device cuda \
  --batch_size 128 \
  --cost_lambda 0.05 \
  --robust_min_positive_models 1 \
  --robust_epsilon 0.20 \
  --max_dummy_steps 10 \
  --seed 0 \
  --random_epsilon 0.0
```

`--random_epsilon 0.0` reproduces the deterministic E2b result. The script also supports optional randomized action selection for follow-up ablations, but deterministic E2b should be treated as the preserved baseline.
