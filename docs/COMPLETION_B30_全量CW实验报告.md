## E2b 演进历史

| 版本 | 预算 | 随机 ε | Completion | WC | TF held-out |
|------|------|------|------|------|------|
| 基础版 512 | 15% | 0 | 无 | 17.77% | 17.77% |
| 基础版全量 | 15% | 0 | 无 | 17.84% | 17.84% |
| **Completion 全量** | **30%** | **0.5** | **有** | **13.37%** | **10.20%** |

## 抗对抗训练预览（512 子集）

| 方法 | 带宽 | DF 自适应 | AWF 自适应 |
|------|------|------|------|
| E2b b20 ε=0.1, 无 completion | 7.60% | 65.04% | 81.64% |
| Completion b20 ε=0.5 | 17.51% | 17.19% | 18.36% |
| Completion b30 ε=0.5 | 25.13% | 11.72% | 14.84% |

无随机化 + 无补全时，2 epoch 对抗微调即可破防（65-82% 恢复率）。
加入随机化 + 补全后，自适应攻击恢复率降至 12-18%。

## 关键提升

1. **TF held-out: 17.84% → 10.20%**（-7.64pp）——补全模式首次有效压制 TF
2. **DF: 11.20% → 9.94%**（-1.26pp）——小幅改善
3. **AWF: 6.07% → 4.95%**（-1.12pp）——已很好，继续改善
4. **全翻率: ~76% → 78.75%**——多覆盖 2pp 样本
5. 代价：带宽 7% → 24.5%（在抗对抗应用场景下可接受）

## 设计理念

```
干净流量
    ↓
RF 关键点 → 分层 Top128 候选（5 维交叉生成）
    ↓
三模型评估（RF / DF / AWF）
    ↓
加权分数 = 0.8×gain_rf + 0.1×gain_df + 0.1×gain_awf - λ×成本
    ↓
ε-greedy 选择动作 → 应用 → 循环直到全翻或预算耗尽
    ↓
Completion: 用剩余带宽随机填满有效候选
```

### 为什么选这三个模型

| 模型 | 攻击视角 | 对应表征族 |
|------|---------|------|
| RF（sklearn） | TAM / burst 统计 | Burst 族 |
| DF（CNN） | 方向序列长程模式 | DIR 族 |
| AWF（浅 CNN） | 方向序列局部模式 | DIR 族（浅层变体） |

不同攻击视角需要同时被欺骗，防御才具有跨架构泛化能力。

### 候选空间

动作由五维交叉组合生成：

| 维度 | 来源 | 取值 |
|------|------|------|
| 窗口 | RF TAM 关键点峰值 | 最多 8 个 |
| 锚点 | 7 类结构位置 | 关键点偏移、速率峰值、方向切换点、间隙等 |
| 剂量 | 绝对 + 相对 | {1,2,4,8,16,32} + {10%-100% 窗口流量} |
| 宽度 | 注入范围 | 窗口长度、半长、8、16、32 |
| 模式 | 方向策略 | 方向平衡、因果掩码 |

约 3 万条原始组合 → 预算过滤 → 去重 → 结构评分取 Top128。
